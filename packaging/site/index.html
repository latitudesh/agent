Latitude.sh Agent packages

apt and dnf repositories for lsh-agent, which keeps a server's UFW firewall in sync with the Latitude.sh Firewall. Ubuntu 22.04+, Debian 12+ and the RHEL family 9+ (AlmaLinux, Rocky Linux, Oracle Linux), on amd64 and arm64.

Install

The dashboard gives you this command, with your IDs filled in: open your firewall, go to Overview and expand Agent Installation.

curl -fsSL https://packages.lsh.io/install.sh \
  | sudo bash -s -- -firewall <firewall_id> -project <project_id>

It installs the agent from this repository, enables UFW with safe defaults (deny incoming, allow outgoing, allow SSH) and starts the lsh-agent service. Add -version <version> to pin a release.

Use the repository directly

Debian and Ubuntu:

sudo curl -fsSLo /etc/apt/sources.list.d/lsh-agent.sources \
  https://packages.lsh.io/apt/lsh-agent.sources
sudo apt-get update
sudo apt-get install -y lsh-agent

RHEL family (ufw comes from EPEL):

sudo dnf install -y epel-release   # Oracle Linux: oracle-epel-release-el9 / -el10
sudo curl -fsSLo /etc/yum.repos.d/lsh-agent.repo \
  https://packages.lsh.io/rpm/lsh-agent.repo
sudo dnf install -y ufw lsh-agent

Install ufw by name, as above: dnf removes packages that came in only as a dependency, so removing the agent would otherwise remove the firewall too.

The package does not configure the host: see the README for binding it to your firewall and enabling UFW. Both repositories are signed with the same key, which lsh-agent.sources and lsh-agent.repo already reference.

Uninstall

On a host set up with the installer:

curl -fsSL https://packages.lsh.io/uninstall.sh | sudo bash

This also resets and disables UFW. If you installed only the package, or want to keep UFW and its rules, run sudo apt-get purge lsh-agent or sudo dnf remove lsh-agent instead.
